Cek Barang Belum Terdisplay

Upload export stock by bin. Tools ini mencari Generic Code yang stoknya ada di zone Warehouse tapi belum muncul di Selling area (zone Sales Area atau bin berawalan S), supaya tim toko tahu barang mana yang perlu segera dipajang.

WarehousetanpaSelling area=Belum terdisplay
Klik untuk pilih file, atau drag & drop di sini
Format .xlsx, .xls, atau .csv. Kolom wajib: Generic Code dan Zone Code. Artikel berawalan 98 & 81 (bukan barang jual) otomatis dikecualikan.

Barang yang tidak terlihat, tidak akan terjual.

Setiap generic yang masih tersimpan di gudang adalah peluang penjualan yang belum kita ambil. Pelanggan hanya bisa memilih apa yang mereka lihat di area penjualan, jadi pastikan semua generic punya wakil di display. Satu artikel yang naik ke rak hari ini bisa jadi transaksi berikutnya.

Foto produk dari master artikel

Foto diambil dari file master foto (kolom Seller SKU, Color, Gambar1–Gambar8) dan dicocokkan lewat Generic Code dan warna.

  1. Klik Pilih file master (.xlsx), lalu pilih file master foto terbaru. Foto langsung aktif di tools ini.
  2. Supaya berlaku untuk semua tim, klik Unduh gambar.json.
  3. Upload gambar.json ke repo GitHub (Add file → Upload files) bersama index.html, tunggu 1–2 menit, lalu tekan Ctrl+F5.
